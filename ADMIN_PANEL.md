# 🎛️ Админ-панель UstazOn

Веб-интерфейс для управления базой данных на базе SQLAdmin.

## 📋 Возможности

- ✅ Просмотр и редактирование всех таблиц
- ✅ Поиск по записям
- ✅ Сортировка
- ✅ Пагинация (25/50/100/200 записей на страницу)
- ✅ Создание новых записей
- ✅ Удаление записей
- ✅ Детальный просмотр

## 🚀 Запуск

### 1. Запустите базу данных

```bash
docker compose up -d
```

### 2. Запустите сервер FastAPI

```bash
cd backend
poetry run uvicorn src.main:app --reload --port 8000
```

### 3. Откройте админ-панель

Откройте в браузере: **http://localhost:8000/admin**

## ⚙️ Настройки

### Изменение количества записей на страницу

По умолчанию: 50 записей. Можно выбрать: 25, 50, 100, 200.

Изменить можно в файле `src/admin/views.py`:

```python
page_size = 50
page_size_options = [25, 50, 100, 200]
```

### Отключение удаления для модели

Например, для пользователей удаление отключено:

```python
class UserAdmin(ModelView, model=User):
    can_delete = False  # Запрещаем удаление
```

### Добавление новой модели

1. Создайте класс в `src/admin/views.py`:

```python
class MyModelAdmin(ModelView, model=MyModel):
    name = "Моя модель"
    name_plural = "Мои модели"
    icon = "fa-solid fa-star"

    column_list = [MyModel.id, MyModel.name]
    column_searchable_list = [MyModel.name]

    can_create = True
    can_edit = True
    can_delete = True
```

2. Добавьте в `src/admin/setup.py`:

```python
from .views import MyModelAdmin

def setup_admin(app: FastAPI) -> Admin:
    admin = Admin(app, engine)
    admin.add_view(MyModelAdmin)
    return admin
```

## 🔒 Безопасность

⚠️ **ВАЖНО**: В текущей версии админ-панель доступна без аутентификации!

Для production необходимо добавить аутентификацию:

```python
from sqladmin.authentication import AuthenticationBackend

class AdminAuth(AuthenticationBackend):
    async def login(self, request):
        # Проверка логина/пароля
        pass

    async def logout(self, request):
        pass

    async def authenticate(self, request):
        # Проверка авторизации
        pass

admin = Admin(
    app,
    engine,
    authentication_backend=AdminAuth(secret_key="your-secret-key")
)
```

## 🐛 Устранение неполадок

### Ошибка подключения к БД

```
ConnectionRefusedError: [Errno 61] Connection refused
```

**Решение**: Запустите Docker контейнер с PostgreSQL:
```bash
docker compose up -d
```

### Страница /admin не открывается

**Решение**:
1. Проверьте, что сервер запущен: `curl http://localhost:8000/health`
2. Проверьте логи: `docker compose logs backend`
3. Перезапустите сервер

### Медленная загрузка больших таблиц

**Решение**: Уменьшите количество записей на страницу:
```python
page_size = 25  # вместо 50
```
