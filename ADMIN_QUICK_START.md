# 🚀 Быстрый старт админ-панели

## Запуск

1. **Запустите PostgreSQL:**
   ```bash
   docker compose up -d
   ```

2. **Запустите сервер:**
   ```bash
   cd backend
   poetry run uvicorn src.main:app --reload --port 8000
   ```

3. **Откройте админку:**
   ```
   http://localhost:8000/admin
   ```

## 📊 Доступные модели

- **Пользователи** (10,690) - Управление пользователями
- **Карточки** (23,941) - Учебные материалы
- **ҚМЖ** (10,628) - Календарные планы
- **Тесты** (167) - Тесты с вопросами и ответами
- **Предметы** (20) - Школьные предметы
- И другие...

## 🔧 Исправлена проблема "Too many fields"

Добавлен параметр `form_columns` для всех моделей, что ограничивает количество полей в формах и решает проблему с WTForms.
